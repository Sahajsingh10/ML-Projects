# Fitness Trainer Chatbot with RAG

A fitness-focused conversational AI project that combines **parameter-efficient fine-tuning (LoRA)** with **Retrieval-Augmented Generation (RAG)**. The project fine-tunes a Llama 2-based causal language model on fitness instruction data, then augments generation with fitness knowledge retrieved from a Chroma vector database.

## Project Overview

This repository contains two main notebooks:

- `Fitness_trainer_chatbot.ipynb` — fine-tunes the language model using LoRA/PEFT.
- `Fitness_chatbot_(RAG).ipynb` — builds the retrieval pipeline and generates answers using retrieved fitness context.

The project was designed to compare model responses with and without retrieved domain context.

## Architecture

```text
Fitness instruction dataset
        |
        v
Llama 2-based model
        |
   LoRA / PEFT
        |
        v
Fine-tuned fitness model
        |
        +-----------------------------+
                                      |
Fitness knowledge -> text chunking -> embeddings
                                      |
                                  ChromaDB
                                      |
User question -> similarity search -> retrieved context
                                      |
                                      v
                         Fine-tuned model + context
                                      |
                                      v
                             Generated response
```

## Fine-Tuning

The fine-tuning notebook uses:

- **Llama 2 7B domain-tuned model**
- **LoRA / PEFT** for parameter-efficient fine-tuning
- **4-bit quantization** with BitsAndBytes
- **TRL SFTTrainer**
- Hugging Face `datasets` and `transformers`

Training configuration in the notebook includes:

- 170 instruction/response training examples
- 10 training epochs
- Learning rate: `2e-4`
- Per-device batch size: `2`
- LoRA rank: `64`
- LoRA alpha: `16`
- LoRA dropout: `0.1`
- Maximum sequence length: `512`

## Retrieval-Augmented Generation

The RAG notebook creates a local knowledge base using:

- **Hugging Face Sentence Transformers**
- `all-MiniLM-L6-v2` embeddings
- **ChromaDB** vector storage
- LangChain's `RecursiveCharacterTextSplitter`

Current notebook configuration:

- Chunk size: `300`
- Chunk overlap: `100`
- 150 chunks generated from the included fitness knowledge source
- Similarity-based retrieval through ChromaDB

Retrieved passages are inserted into the generation prompt as context before the fine-tuned model produces its answer.

## Example Workflow

For a question such as:

```text
Can you recommend effective ab exercises?
```

the RAG pipeline:

1. Embeds the question.
2. Searches ChromaDB for semantically relevant fitness passages.
3. Adds the retrieved passages to the prompt.
4. Sends the grounded prompt to the fine-tuned model.
5. Generates a fitness-focused response.

The notebook also runs the same type of question without retrieval so the outputs can be compared.

## Running the Project

The notebooks were developed in **Google Colab** and contain Google Drive paths. To run them:

1. Open the notebooks in Colab.
2. Enable a GPU runtime.
3. Install the dependencies shown at the beginning of each notebook.
4. Update the Google Drive paths for your environment.
5. Run `Fitness_trainer_chatbot.ipynb` for fine-tuning.
6. Run `Fitness_chatbot_(RAG).ipynb` to build the vector store and test RAG inference.

Some Hugging Face model operations may require a Hugging Face access token.

## Notes
